🏗️ 1. Builder Design Pattern

Creational Pattern

Intent: Separates the construction of a complex, multi-day Itinerary object from its representation, allowing the same construction process to create varying schedules.

Source: src/builder.js (TripDirector & CustomizedTripBuilder) JavaScript 
// 1. DIRECTOR: TripDirector enforces the stepwise construction sequence
export class TripDirector {
  constructor(builder) {
    this.builder = builder;
  }

  constructTrip(formData) {
    this.builder.reset();
    this.builder.setCoreParameters(
      formData.destination,
      formData.travelers,
      formData.duration,
      formData.budget
    );
    this.builder.buildTransportation(formData.transport);
    this.builder.buildAccommodation(formData.accommodation);
    this.builder.buildAttractionsAndPace(formData.attractions, formData.pace);
    this.builder.buildDayWisePlan();
    this.builder.calculateItemizedCosts();
    return this.builder.getResult(); // Returns fully constructed Itinerary product
  }
}
Trigger / User Action User selects destination, duration, transport, and hotel on planner.html and submits the form.
Input Parameters { destination: "Goa", duration: 4, travelers: 2, transport: "Flight", accommodation: "3-Star Hotel" }
Output Result Structured Itinerary object with day-by-day schedules (morning, afternoon, evening), room counts, and verified itemized pricing.
Screenshot Target Planner Form on planner.html OR the Day-Wise Itinerary Schedule timeline on output.html.

🏭 2. Factory Method Design Pattern

Creational Pattern

Intent: Defines creator interfaces for creating transport and accommodation service objects, letting subclasses decide which concrete service to instantiate based on user selection.

Source: src/factory.js (TransportationFactoryProvider & Concrete Services) JavaScript 
// Creator Factory Provider for Transportation
export class TransportationFactoryProvider {
  static createTransportService(type) {
    switch (type.toLowerCase()) {
      case 'flight':
        return new FlightService();
      case 'train':
        return new TrainService();
      case 'bus':
        return new BusService();
      case 'car rental':
      case 'car':
        return new CarRentalService();
      default:
        return new FlightService();
    }
  }
}

// Concrete Product implementing calculateCost() and getIncludedPerks()
export class FlightService extends ITransportationService {
  calculateCost(travelers, destination) {
    const baseAirfare = 5200;
    return travelers * (baseAirfare + 800); // Base airfare + airport transfers
  }
  getIncludedPerks() {
    return ["15kg Check-in Luggage", "Complimentary In-Flight Meal", "Fast-Track Security"];
  }
}
Trigger / User Action User toggles between transit modes (Flight, Train, Bus, Car) or accommodation tiers (Budget, 3-Star, 5-Star, Resort).
Concrete Product Created FlightService, ThreeStarHotelService, etc., each encapsulating its own rate formulas and amenity rules.
Screenshot Target The Transportation and Accommodation summary tiles and verified cost breakdown grid on output.html.

🛡️ 3. Decorator Design Pattern

Structural Pattern

Intent: Dynamically attaches additional responsibilities (insurance, VIP concierge, carbon offset) to BaseTripPackage at runtime without subclass inheritance explosion.

Source: src/decorator.js (BaseTripPackage & Concrete Decorators) JavaScript 
// 1. Concrete Component: BaseTripPackage
export class BaseTripPackage extends TripPackageComponent {
  constructor(itinerary) {
    super();
    this.baseCost = itinerary.costBreakdown.totalEstimatedCost;
  }
  getCost() { return this.baseCost; }
  getDecoratedPerks() { return ["Standard Itinerary Coordination", "Confirmed Vouchers"]; }
}

// 2. Concrete Decorator: TravelInsuranceDecorator
export class TravelInsuranceDecorator extends TripPackageDecorator {
  constructor(tripPackage) {
    super(tripPackage);
    this.insuranceCost = 1200;
  }
  getCost() {
    return this.wrappedPackage.getCost() + this.insuranceCost; // Dynamically layers price
  }
  getDecoratedPerks() {
    return [...this.wrappedPackage.getDecoratedPerks(), "Emergency Medical Hospitalization up to ₹10 Lakhs"];
  }
}

🏛️ 4. Facade Design Pattern

Structural Pattern

Intent: Provides a unified, simplified master API (planAndBookCompleteTrip()) that shields clients from the complexity of coordinating Builder, Factory Method, Decorator, Strategy, and Services.

Source: src/facade.js (SmartTripPlannerFacade) JavaScript 
export class SmartTripPlannerFacade {
  constructor() {
    this.builder = new CustomizedTripBuilder();
    this.director = new TripDirector(this.builder);
    this.weatherService = new WeatherService();
    this.currencyService = new CurrencyService();
    this.bookingService = new BookingService();
    this.strategyContext = new PacingStrategyContext("Moderate");
  }

  planAndBookCompleteTrip(formData) {
    // 1. Delegate construction to Builder & Factory Method Subsystem
    const itinerary = this.director.constructTrip(formData);

    // 2. Delegate add-on layering to Decorator Subsystem
    const decoratedPackage = TripDecoratorManager.applyDecorators(itinerary, formData.addons);

    // 3. Delegate climate telemetry and currency conversion to Services
    const weather = this.weatherService.getWeatherReport(formData.destination);
    const currency = this.currencyService.convertAndFormat(decoratedPackage.getCost(), formData.targetCurrency);

    // 4. Delegate daily pacing timeline to Strategy Subsystem
    this.strategyContext.setStrategy(formData.pace || "Moderate");
    this.strategyContext.regeneratePlan(itinerary);

    // 5. Assemble unified Master Plan object
    return { itinerary, packageSummary: decoratedPackage.getPackageSummary(), weather, currency };
  }
}
Client Call in UI const masterPlan = new SmartTripPlannerFacade().planAndBookCompleteTrip(formData);
Subsystems Coordinated Builder + Factory Method (construction), Decorator (add-ons), Strategy (pacing), Weather & Currency Services.
Screenshot Target The smooth transition and loading overlay on planner.html to the fully populated output.html view.

🧭 5. Strategy Design Pattern

Behavioral Pattern

Intent: Defines a family of interchangeable travel pacing algorithms (Relaxed, Balanced, Fast-Paced), encapsulating each one and making them swappable at runtime.

Source: src/strategy.js (ItineraryStrategy & PacingStrategyContext) JavaScript 
// Context maintaining reference to the active Strategy
export class PacingStrategyContext {
  constructor(initialPaceKey = "Moderate") {
    this.strategies = {
      "Relaxed": new RelaxedLeisureStrategy(),     // 3-5 km/day, 4 hrs rest
      "Moderate": new BalancedExplorerStrategy(),   // 6-9 km/day, 2-3 hrs rest
      "Fast": new FastPacedAdventureStrategy()      // 10-14 km/day, 1 hr rest
    };
    this.currentStrategy = this.strategies[initialPaceKey] || this.strategies["Moderate"];
  }

  setStrategy(paceKey) {
    if (this.strategies[paceKey]) {
      this.currentStrategy = this.strategies[paceKey]; // Swaps algorithm at runtime
    }
  }

  regeneratePlan(itinerary) {
    // Executes active strategy algorithm to recalculate morning, afternoon, evening slots
    itinerary.dayWisePlan.forEach(day => {
      const schedule = this.currentStrategy.generateDaySchedule({ dayNumber: day.day, ... });
      Object.assign(day, schedule);
    });
  }
}

🔔 6. Observer Design Pattern

Behavioral Pattern

Intent: Defines a one-to-many publish-subscribe dependency so that when the trip state changes (cost, currency, pace, activities), all dependent UI components update automatically.

Source: src/observer.js (TripEventSubject & Concrete Observers) JavaScript 
// 1. Subject / Observable maintaining registered observers
export class TripEventSubject {
  constructor() {
    this.observers = new Map(); // eventName -> Set of observers
  }
  subscribe(eventName, observer) {
    if (!this.observers.has(eventName)) this.observers.set(eventName, new Set());
    this.observers.get(eventName).add(observer);
  }
  notify(eventName, eventData, context) {
    if (this.observers.has(eventName)) {
      this.observers.get(eventName).forEach(obs => obs.update(eventName, eventData, context));
    }
  }
}

// 2. Concrete Observer: BudgetHealthObserver
export class BudgetHealthObserver extends IObserver {
  update(eventName, eventData, context) {
    const total = context.packageSummary.totalCost;
    const target = context.itinerary.budget;
    const pct = Math.round((total / target) * 100);
    // Dynamically updates progress bar and color (Green: <=100%, Amber: >100%)
    this.renderBudgetHealthGauge(total, target, pct);
  }
}
